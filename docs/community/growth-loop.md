# KALLAX Growth Loop

> Strategy for building a self-sustaining developer community through systematic growth flywheel.

## The Growth Flywheel

```
GitHub Stars
     ↓
Lark/WeChat Community
     ↓
Hosted Showcase
     ↓
Real Use Cases
     ↓
Viral Narratives
     ↓
More GitHub Stars
```

## 5 Stages of the Growth Loop

### Stage 1: GitHub Star Acquisition

**Goal:** Convert curious visitors to engaged stargazers

**KPI:** +100 stars/month

**Tactics:**
- SEO optimization for "Claude Code tools" keywords
- README quality (first impression matters)
- Demo video on landing page
- Comparison articles vs competitors

**Assets:**
- `web/index.html` — GitHub Pages hosted frontstage
- `docs/showcases/cases/*.md` — Real use case documents

### Stage 2: Community Channel Entry

**Goal:** Convert stars to community members

**KPI:** 50% star-to-Lark conversion, 20 Lark members/month

**Tactics:**
- Clear call-to-action in README
- Lark/WeChat QR codes prominently displayed
- Community README with clear joining process
- First-week engagement sequence

**Assets:**
- `docs/community/README.md` — Community landing
- `docs/community/lark-qr-placeholder.md` — Lark entry
- `docs/community/wechat-qr-placeholder.md` — WeChat entry

### Stage 3: Hosted Showcase Platform

**Goal:** Showcase real value to attract more users

**KPI:** 1 showcase featured/month

**Tactics:**
- Showcase submission template
- Review process for featured showcases
- Metrics-driven case studies
- SEO optimization for showcase content

**Assets:**
- `web/showcase/index.html` — Showcase gallery
- `docs/showcases/cases/` — Individual case studies
- `docs/showcases/template.md` — Submission template

### Stage 4: Real Use Case Accumulation

**Goal:** Build proof of value through documented cases

**KPI:** 10 documented use cases by EOY, 20 by mid-year

**Tactics:**
- User interview program
- Case study writing support
- Quantitative metrics collection
- Diverse industry coverage

**Assets:**
- `confluence/research/kallax-growth-loop-2026-08-05.md` — Full strategy
- `docs/showcases/` — All showcase documents

### Stage 5: Viral Narrative Creation

**Goal:** Turn use cases into shareable stories

**KPI:** 3 articles shared on Hacker News/Lobsters/Reddit

**Tactics:**
- Hacker News "Show KALLAX" posts
- Dev.to and Medium articles
- Twitter/X developer advocacy
- Podcast appearances

**Assets:**
- Growth metrics dashboard
- Testimonial collection
- Feature highlight documentation

## ICP (Ideal Customer Profile)

### ICP 1: Individual Developer (70%)

**Profile:**
- Solo developer or small team
- Uses Claude Code for personal projects
- Values automation and workflow efficiency
- Active on GitHub and developer communities

**Acquisition:** Content marketing, SEO, community word-of-mouth

### ICP 2: Small Team Lead (20%)

**Profile:**
- Tech lead or engineering manager
- Team of 2-10 developers
- Interested in AI-assisted development workflows
- Looking for team coordination tools

**Acquisition:** LinkedIn, professional communities, demos

### ICP 3: Enterprise Developer Advocate (8%)

**Profile:**
- Developer relations or technical marketing
- Evaluating tools for team adoption
- Values documentation and support quality
- Budget holder for developer tools

**Acquisition:** Direct outreach, conference presence, partnerships

### ICP 4: Open Source Contributor (2%)

**Profile:**
- Active open source maintainer
- Interested in AI tooling for OSS
- Values transparency and community
- Potential core contributor

**Acquisition:** Community engagement, contribution pathway
