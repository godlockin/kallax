## Community Guidelines

### Topic Areas

- **General Discussion:** Project updates, announcements, general questions
- **Showcases:** Share your KALLAX use cases and workflows
- **Development:** Feature requests, bug reports, contributions
- **Learning:** Tutorials, best practices, tips and tricks

### How to Ask Questions

Before posting, please:

1. **Search existing threads** — Your question may already be answered
2. **Use the question template:**

```
## Question Template

### Context
What are you trying to achieve?

### What I've tried
[List steps you've taken]

### Expected vs Actual
[What you expect vs what happens]

### Environment
- KALLAX version:
- OS:
- Claude Code version:
```

3. **Be specific** — Include error messages, logs, and reproduction steps
4. **Be patient** — Community members will respond when available

### Community Rules

1. **Be respectful** — Follow the [Code of Conduct](CODE_OF_CONDUCT.md)
2. **Stay on topic** — Keep discussions relevant to KALLAX
3. **No spam** — Self-promotion requires prior approval
4. **Help others** — Share your knowledge and experience
5. **Use English in Lark** — Use Chinese in WeChat for accessibility

## Showcase Program

Share your KALLAX workflow and get featured on our [showcase page](../web/showcase/index.html).

**Showcase Criteria:**
- Real production use case
- Measurable productivity gains
- Reproducible workflow

**Submit Your Showcase:**
1. Create a markdown file in `docs/showcases/cases/`
2. Include: workflow description, metrics, screenshots
3. Submit PR with title: `feat(showcase): Add [Your Name] use case`
