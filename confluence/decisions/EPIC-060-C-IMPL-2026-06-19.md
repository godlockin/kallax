## 3. 架构 决策 (跟 eket 4 级降级 模式 联合)

### 3.1 1 interface + 2 implementations (跟 Rule 5 DRY 联合)

```
                     ┌──────────────────────────┐
                     │  PubSubBus (interface)   │
                     │  - publish(channel,data) │
                     │  - subscribe(channel,h)  │
                     │  - unsubscribe(channel)  │
                     │  - close()               │
                     │  - readonly mode         │
                     └──────────┬───────────────┘
                                │
                  ┌─────────────┴─────────────┐
                  │                           │
        ┌─────────▼─────────┐      ┌──────────▼──────────┐
        │ RedisPubSubBus    │      │ InMemoryPubSubBus   │
        │ (L3 production)   │      │ (L2 fallback/test)  │
        │ - ioredis pub +   │      │ - in-process Map    │
        │   sub clients     │      │ - 0 ioredis dep     │
        │ - cross-process   │      │ - single-process    │
        │ - JSON serialize  │      │ - reference sem.    │
        └───────────────────┘      └─────────────────────┘
```

### 3.2 关键 决策 (跟 AGENTS.md 4 级降级 联合)

| 维度 | RedisPubSubBus (L3) | InMemoryPubSubBus (L2) | 理由 |
|------|---------------------|------------------------|------|
| 跨进程 | ✅ 多 Redis 客户端 | ❌ 单进程 | ioredis 真价值在 跨进程 |
| 数据 序列化 | JSON.stringify/parse | 类型保持 (reference) | 跨进程 必须 序列化 |
| Channel prefix | `kallax:pubsub:` | (none, caller-specified) | 避免 共享 Redis 冲突 |
| 依赖 | `ioredis` (required, EPIC-060-C 启用) | 0 外部依赖 | L2 必须 可降级 |
| 错误 处理 | publisher.on('error') + handler try/catch + logger | handler try/catch + logger | 跟 Rule 3 联合 |
| Cleanup | registerCleanupHandler (SIGINT/SIGTERM) | registerCleanupHandler | 跟 process-cleanup 联合 |

### 3.3 跟 eket 4 级降级 模式 联合 (file:line `AGENTS.md:344-373`)

```
┌─────────────────────────┐
│  Level 3: Redis + Full  │  ← RedisPubSubBus (production, multi-process)
└──────────┬──────────────┘
           ↓ Redis down / config.mode='memory'
┌─────────────────────────┐
│  Level 2: In-Memory     │  ← InMemoryPubSubBus (degraded / tests)
└──────────┬──────────────┘
           ↓ Node.js crash
        (rust / shell fallback out of scope)
```

Factory `createPubSubBus({mode, redis?})` 暴露 2 选 1 切换. 跟 v2.7.4 B5.3 治根 联合.
