## 2. 因果分析

| 失败 | 根因 | 跟 EPIC-209 因果 |
|------|------|-----------------|

| **check-body** | PR body 字段不全 | EPIC-209 PR body 模板不符 |
| **Rust Lint** | `ticket_engine.rs` 格式不符 (rustfmt 不通过) | **历史债, 跟 EPIC-209 无关** (代码早就未 fmt) |
| **Forbidden Patterns** | regex 命中 (跟 EPIC-158 false-positive 关联) | **历史债, 跨周 regex 调整** |
| **Security Audit** | 10 vulnerabilities (body-parser / esbuild / vite / vitest) | **历史债, 跨周 npm audit fix** |

**结论**: 5 个失败中 2 个 (check-dco + check-body) 跟 EPIC-209 PR 格式有关, 可在 EPIC-210 修. 3 个 (Rust Lint / Forbidden Patterns / Security Audit) 是历史债, 备案债 Q3 2026 跟 EPIC-155/176/208 一起 re-promote.
