## 1. Onboarding 5 分钟 实战

### KALLAX (3 步 + 1 速查)

```
cargo install kallax → kallax init → kallax master:start
```

**证据**:
- `CLAUDE.md` line 8: `Setup (3 步)` (1 行, 0 narrative)
- `CLAUDE.md` 3.3KB cold start, 跟 v2.7.6 54KB 比 16.4x 缩减 (跟 `docs/ARCHITECTURE.md` §11 KPI 表 1:1 联合)
- 4 lazy load docs (`CHEATSHEET.md` 27 行 / `5-levels.md` 143 行 / `4-roles.md` 181 行 / `q18-decision-model.md` 543 行)

**实战路径** (跟 P-003 lazy load 1:1 联合):
1. `cargo install kallax` → binary 装好 (1 command, ~30s 跟 eket 1:1 1:1)
2. `kallax init` → 写 `.kallax/state/instance_config.yml` (role 字段)
3. `kallax master:start` → 启动 master + 1+4 sub-roles

### eket (4 层 setup, 推测 10+ min)

**证据**:
- `references/setup-guide.md`: 4 层 (Level 0-4: Shell / Rust / Node.js / SQLite / Docker)
- 必装项: Rust ≥1.75 + Node.js ≥20 + (可选) Docker + Redis
- 验证: `eket --version` + `eket system:doctor`

**实战路径**:
1. Level 0: `chmod +x lib/adapters/hybrid-adapter.sh` → doctor
2. Level 1: `cd rust && cargo build --release` (~30-60s 首次) + PATH export
3. Level 2: `cd node && npm ci && npm run build` + `.env` cp
4. Level 4: `mkdir sqlite` + `npm rebuild better-sqlite3`

### 对比

| 维度 | KALLAX v3.5.0-hotfix1 | eket v2.9.2 | 评价 |
|------|---------------------|------------|------|
| **Onboarding 命令数** | 3 (install + init + start) | 4 (Level 0+1+2+4) | **KALLAX 胜** (1 步少) |
| **Onboarding 文档大小** | CLAUDE.md 3.3KB | SKILL.md ~200 行 (估) + setup-guide.md 4 层 | **KALLAX 胜** (3.3KB 极简) |
| **Onboarding 时间 (推)** | <5 min (cargo install + init + start) | 10+ min (cargo + npm + .env + sqlite) | **KALLAX 胜** |
| **必装 runtime** | Rust ≥1.75 | Rust ≥1.75 + Node.js ≥20 | **KALLAX 胜** (1 runtime) |
| **PATH 配置** | `cargo install` 自动 (PATH 走 cargo 默认) | 手动 `export PATH=~/.local/bin` (zsh/bash 各自) | **KALLAX 胜** |
| **冷启动 (binary)** | ~5ms (Rust 1 binary) | ~30-60s (cargo build) | **KALLAX 胜** (跟 ARCHITECTURE.md §11 KPI 1.6x 加速 1:1 联合) |

**关键观察**: KALLAX 极简 onboarding 跟 `Q18 决策模型` "诚实修正" 战略 一致 — 3 步 ≤ 5 min, eket 4 层 ≥ 10 min, 实战门槛 KALLAX 显著低.
