1. `git diff --stat` 验证
2. 0 source code change (`.ts/.rs/.js/.sh` 为空)
3. ≤ 100 行 diff (`git diff --shortstat`)
4. 单 commit (`git log --oneline origin/miao..HEAD | wc -l = 1`)
