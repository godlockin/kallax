# EPIC-301 设计 — Worktree 卫生防御 gate

> **Status**: design complete, in implementation
> **Author**: master (2026-08-28)
> **联动**: `worktree-debt-retrospective-2026-08-28.md`, `worktree-cleanup-2026-08-28.md`, [[feedback-worktree-isolation]], [[feedback-worktree-cleanup-local-only]]

## 1. 设计目标

补 **3 个 0 防御 gap**, 防本次 79 worktree + 165 branch 爆炸复发:

1. **post-checkout 提示**: 切到 main 分支时提示 `git worktree prune`
2. **pre-commit 阈值告警**: worktree > 50 时 exit 1 阻断
3. **verify 脚本独立检查**: `scripts/verify/check-worktree-hygiene.sh` 跑 5-Level Verify

## 2. Hook 设计

### 2.1 check-worktree-hygiene.sh (post-checkout)

**触发**: `git checkout` 切到 miao / main / testing 3 个主分支任一

**动作**: 
```
echo "==> Worktree 卫生提示"
echo "  当前 worktree 数: $(git worktree list | wc -l)"
if [[ $(git worktree list | wc -l) -gt 50 ]]; then
  echo "  ⚠ 超过 50 阈值, 建议运行:"
  echo "    bash /tmp/cleanup-worktree-batch4.sh"
  echo "  或:"
  echo "    git worktree prune"
fi
echo "  完整审计: bash scripts/verify/check-worktree-hygiene.sh"
```

**退出码**: 0 (advisory, 不阻塞)

### 2.2 check-worktree-count.sh (pre-commit)

**触发**: 每次 `git commit` 前

**动作**:
```bash
wt_count=$(git worktree list | wc -l)
if [[ ${wt_count} -gt 50 ]]; then
  echo "FAIL: worktree 数 ${wt_count} > 50" >&2
  echo "  清理脚本: bash /tmp/cleanup-worktree-batch4.sh" >&2
  exit 1
fi
```

**退出码**: 
- 0: worktree ≤ 50 → PASS
- 1: worktree > 50 → FAIL (阻断 commit)

**豁免**: `KALLAX_HOOK_BYPASS=1` (跟现有 pre-commit 1:1 一致)

### 2.3 install.sh 更新

`scripts/hooks/install.sh` 加 2 个 hook 安装项 (跟现有 install 1:1 pattern):
- `git config core.hooksPath` 不变
- 增加 `post-checkout` symlink 到 `scripts/hooks/check-worktree-hygiene.sh`
- `pre-commit` 中加 `check-worktree-count.sh` 调用

## 3. Verify 脚本设计

### 3.1 scripts/verify/check-worktree-hygiene.sh

**5-Level Verify** (跟 EPIC-224/225/280 同型):

```
L1 存在性: 2 个 hook 文件存在 + 可执行
L1 verify 脚本自身存在 + 可执行
L2 语法: bash -n 2 个 hook + verify 脚本
L2 函数: check_worktree_count + check_worktree_hygiene 函数可用
L3 pattern: install.sh 引用 check-worktree-count.sh
L4 集成: tests/integration/check-worktree-hygiene.test.sh 存在 + 可执行
```

**退出码**: 0=PASS, 1=FAIL (跟 immutable 二态契约一致, 不跟 scan-dead-code 三态混)

### 3.2 tests/integration/check-worktree-hygiene.test.sh

**10 个 test case**:

| # | 场景 | 预期 |
|---|------|------|
| T1 | worktree=10 (低) | check-worktree-count exit 0 |
| T2 | worktree=60 (高) | check-worktree-count exit 1 |
| T3 | 切到 miao | post-checkout 输出 "Worktree 卫生提示" |
| T4 | 切到 feature | post-checkout 不输出 |
| T5 | verify 脚本存在 | exit 0 |
| T6 | verify 语法 | exit 0 |
| T7 | install.sh 引用 check-worktree-count | exit 0 |
| T8 | KALLAX_HOOK_BYPASS=1 worktree=60 | exit 0 (豁免) |
| T9 | 模拟 post-checkout 触发, worktree 60 | 输出建议清理脚本路径 |
| T10 | 整体 hook health | install.sh --verify exit 0 |
