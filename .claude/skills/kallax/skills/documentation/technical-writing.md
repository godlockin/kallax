# 技术写作技能

## 技能定义
编写清晰、准确、易懂的技术文档的能力。

## 适用场景
- API文档编写
- 用户指南
- 架构文档
- 操作手册

## 执行流程

### 1. 受众分析
- 读者背景
- 知识水平
- 使用场景

### 2. 结构设计
- 信息组织
- 导航设计
- 逻辑顺序

### 3. 内容编写
- 清晰表达
- 示例说明
- 视觉辅助

### 4. 审核优化
- 准确性检查
- 可用性测试
- 持续更新

## 写作原则

### 清晰性
- 使用简单直接的语言
- 避免术语堆砌
- 一个段落一个主题

### 准确性
- 代码示例可运行
- 版本信息准确
- 定期更新维护

### 可用性
- 任务导向结构
- 充分的示例
- 良好的导航

### 一致性
- 统一术语
- 统一格式
- 统一风格
