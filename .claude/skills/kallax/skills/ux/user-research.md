# 用户研究技能

## 技能定义
通过多种方法深入了解用户需求、行为和痛点的能力。

## 适用场景
- 产品发现阶段
- 设计验证
- 用户满意度调研
- 市场研究

## 执行流程

### 1. 研究规划
- 目标定义
- 方法选择
- 样本设计

### 2. 数据收集
- 用户访谈
- 问卷调查
- 行为观察

### 3. 数据分析
- 定性编码
- 定量统计
- 模式识别

### 4. 洞察输出
- 关键发现
- 用户画像
- 设计建议

## 输出格式
```markdown
## 用户研究报告

### 研究概述
- 目标: [研究目标]
- 方法: [研究方法]
- 样本: [样本信息]
- 时间: [研究周期]

### 研究问题
1. 用户如何完成[任务]?
2. 用户在[场景]中的痛点是什么?
3. 用户对[功能]的期望是什么?

### 用户画像

#### 画像1: 效率追求者
**Demographics**
- 年龄: 25-- "我希望一次处理多个任务"

**痛点**
- 信息分散,需要多处查看
- 重复操作多,效率低

**机会**
- 聚合仪表盘
- 批量操作功能

---

### 关键发现

#### 发现1: 导航复杂度高
**证据**:
- 8/12 用户提到难以找到功能
- 平均完成任务需要5.2次点击
- 用户原话: "我总是记不住功能在哪里"

**影响**: 高
**置信度**: 高

**设计建议**:
- 简化导航层级
- 添加搜索功能
- 最近使用快捷入口

#### 发现2: 缺乏操作确认
**证据**:
- 6/12 用户担心误操作
- 3 起因误操作导致的数据丢失
- 用户原话: "点完不知道有没有成功"

**影响**: 中
**置信度**: 高

**设计建议**:
- 添加操作确认
- 提供撤销功能
- 明确的成功/失败反馈
```
