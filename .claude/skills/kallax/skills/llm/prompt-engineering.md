# Prompt 工程技能

## 技能定义
设计和优化LLM提示词的能力，提高AI输出质量和一致性。

## 适用场景
- AI功能开发
- 提示词优化
- 输出质量提升
- 成本控制

## 执行流程

### 1. 需求分析
- 任务类型
- 输出要求
- 质量标准

### 2. 提示词设计
- 角色设定
- 任务说明
- 格式约束

### 3. 测试迭代
- 边界测试
- 效果评估
- 持续优化

### 4. 生产部署
- 版本管理
- 监控评估
- A/B测试

## 输出格式
```markdown
## Prompt 设计文档

### 任务定义
- 目标: [任务目标]
- 输入: [输入格式]
- 输出: [输出格式]
- 质量要求: [评估标准]

### Prompt 结构

#### System Prompt
```
你是一个专业的 [角色]。你的任务是 [任务描述]。

## 你的能力
- 能力1
- 能力2

## 约束
- 约束1
- 约束2

## 输出格式
[格式说明]
```

#### User Prompt Template
```
## 任务
[具体任务]

## 输入
{input}

## 要求
- 要求1
- 要求2

## 输出
请按以下格式输出:
{output_format}
```

### Few-shot 示例
```
## 示例1
输入: [示例输入]
输出: [示例输出]

## 示例2
输入: [示例输入]
输出: [示例输出]

## Prompt 技巧

### 基础技巧
- **明确指令**: 清晰具体的任务说明
- **角色扮演**: 设定专家角色
- **格式约束**: 指定输出格式
- **Few-shot**: 提供示例

### 高级技巧
- **思维链 (CoT)**: "让我们一步步思考"
- **自我一致性**: 多次生成取共识
- **分解任务**: 复杂任务拆分
- **迭代细化**: 多轮对话优化

### 结构化输出
```
请以JSON格式输出:
{
  "analysis": "分析内容",
  "conclusion": "结论",
  "confidence": 0.9
}
```

## 常见问题

### 输出不稳定
- 降低temperature
- 增加示例
- 更具体的约束

### 输出太长/太短
- 明确长度要求
- 提供长度示例
- 使用max_tokens

### 格式不符
- 使用结构化输出
- 提供格式示例
- JSON模式

## 评估框架

| 维度 | 评估方法 | 权重 |
|------|----------|------|
| 准确性 | 人工评估 | 40% |
| 格式符合 | 自动检查 | 20% |
| 一致性 | 多次运行 | 20% |
| 效率 | Token统计 | 20% |
