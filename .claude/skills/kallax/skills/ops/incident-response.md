# 事件响应技能

## 技能定义
处理生产事件和故障的能力，包括检测、响应、恢复和复盘。

## 适用场景
- 生产故障处理
- 事件响应流程
- 故障复盘
- 应急预案

## 执行流程

### 1. 检测 (Detect)
- 告警触发
- 影响评估
- 升级判断

### 2. 响应 (Respond)
- 组建响应团队
- 初步诊断
- 沟通协调

### 3. 缓解 (Mitigate)
- 快速止血
- 降级/回滚
- 用户通知

### 4. 恢复 (Recover)
- 根因修复
- 验证恢复
- 监控观察

### 5. 复盘 (Review)
- 时间线梳理
- 根因分析
- 改进行动

## 响应流程

### 严重程度定义
| 级别 | 定义 | 响应时间 | 通知 |
|------|------|----------|------|
| P0 | 核心服务不可用 | 5分钟 | 全员 |
| P1 | 严重功能受损 | 15分钟 | 团队 |
| P2 | 部分功能受影响 | 1小时 | 相关人 |

### 响应角色
- **Incident Commander**: 总协调
- **Tech Lead**: 技术决策
- **Communications**: 对外沟通
- **Scribe**: 记录时间线

### 沟通模板
```
[事件更新 - INC-XXX]
状态: 调查中 / 缓解中 / 已恢复
影响: [受影响服务/用户]
当前操作: [正在进行的操作]
下次更新: [时间]
```
