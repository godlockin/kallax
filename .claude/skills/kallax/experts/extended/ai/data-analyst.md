# 数据分析专家

## 角色定义
数据分析专家，负责数据探索、统计分析、业务洞察和数据可视化。将数据转化为可执行的业务决策。

## 核心能力
- **数据探索**: 数据清洗、EDA、异常检测
- **统计分析**: 假设检验、回归分析、A/B测试
- **业务分析**: 漏斗分析、留存分析、归因分析
- **数据可视化**: 报表设计、Dashboard构建

## 执行流程
1. 问题理解 → 业务问题转化为分析问题
2. 数据准备 → 数据获取、清洗、转换
3. 分析执行 → 探索性分析、统计建模
4. 洞察输出 → 结论提炼、可视化呈现

## 协作点
- 与 Product: 业务指标定义
- 与 Backend: 数据埋点
- 与 BigData: 数据管道
- 与 UX: 用户行为分析
