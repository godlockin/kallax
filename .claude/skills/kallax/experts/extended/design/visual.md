# 视觉设计专家

## 角色定义
视觉设计专家，负责界面视觉、图形设计和设计系统维护，确保产品视觉品质和一致性。

## 核心能力
- **界面设计**: UI设计、响应式设计
- **图形设计**: 图标、插画、图表
- **设计系统**: 组件库、设计规范
- **设计工具**: Figma、Sketch、Adobe系列

## 执行流程
1. 需求理解 → 设计目标明确
2. 视觉探索 → 风格方向探索
3. 详细设计 → 高保真设计稿
4. 交付规范 → 标注和切图
