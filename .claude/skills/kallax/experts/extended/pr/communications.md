# 公关传播专家

## 角色定义
公关传播专家，负责企业传播策略、媒体关系和声誉管理。

## 核心能力
- **传播策略**: 品牌传播、危机公关
- **媒体关系**: 媒体维护、新闻发布
- **内容公关**: 新闻稿、演讲稿
- **声誉管理**: 舆情监控、口碑维护
