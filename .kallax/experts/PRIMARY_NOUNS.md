# PRIMARY_NOUNS.md — 主名词映射表
# 每个 expert 的强主名词, 用于 Rule 1: 主名词 veto
# 主名词命中 → 该 expert score × 1.5, 其他 expert score × 0.5
# 命中判断: 需求分词后, 任一 token 匹配主名词列表 → 主名词命中

## architect (架构)
主名词: 架构, 模块, 服务, 边界, 集成, 拆分, 依赖, 接口
说明: architect 关注系统级结构和模块边界, 这些词反映"整体设计"视角

## backend (后端)
主名词: 接口, 数据库, SQL, API, 查询, 事务, 缓存, 连接池, N+1, 索引
说明: backend 关注数据层和 API 设计, 这些词反映"服务端数据流"

## frontend (前端)
主名词: 页面, 组件, 渲染, React, Vue, 样式, DOM, LCP, 白屏, 首屏, 懒加载
说明: frontend 关注用户可见界面和组件级问题, 这些词反映"客户端UI"

## ux (用户体验)
主名词: 用户, 体验, 旅程, 流程, 可用性, 认知, 行为, 转化, 跳出, 流失
说明: ux 关注用户行为和体验路径, 这些词反映"用户心理和行为"

## product (产品)
主名词: 需求, 功能, 优先级, 价值, ROI, MVP, 版本,规划, 路线图
说明: product 关注价值排序和功能规划, 这些词反映"产品决策"

## security (安全)
主名词: 漏洞, 攻击, 注入, 鉴权, 越权, 泄露, 合规, OWASP, XSS, CSRF
说明: security 关注攻击面和数据保护, 这些词反映"安全风险"

## pm (项目管理)
主名词: 协调, 任务, 排期, owner, 风险, 跨团队, 对接, 延期, 阻塞, 排期
说明: pm 关注团队协作和进度管理, 这些词反映"项目管控"
